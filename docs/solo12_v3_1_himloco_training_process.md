# Solo12 v3.1 HIMLoco 已完成训练过程

本文保留阶段模型 `model_7540.pt` 的有效训练链，并补充以已验收 `model_8040.pt`
为基线的 armature 动力学适应过程。只列出直接进入所选 checkpoint 继承关系的训练，
不包含接口试跑、参数探针、失败分支以及未被最终模型继承的实验。

## 1. 7540 阶段模型

- 训练任务：`solo12_v3_1_obstacle_final_action_delay`
- 训练 run：`Sep16_17-26-58_obstacle_final_action_delay_500it_seed1`
- 该阶段选定 checkpoint：`model_7540.pt`
- 基础无动作延迟 checkpoint：`model_7100.pt`
- 目标机身高度：`0.32 m`
- 策略周期：`20 ms`（仿真步长 `5 ms`，control decimation 为 4）
- 最终动作延迟：每个环境、每个策略周期独立随机选择
  `0/5/10/15 ms`
- 最终观测延迟：关闭

## 2. 固定机器人和场景设置

- 使用 RobStride RS02 手册中的 48 V 转速—扭矩曲线限制关节输出。
- 电机转速边界按 420 rpm 换算为 `43.9823 rad/s`，不使用旧 URDF 边界作为
  训练能力；calf 经过额外 2:1 传动后为 `21.99115 rad/s`。
- hip、thigh 的外部传动比为 1，calf 的额外传动比为 2。
- 地形沿用 Go1 HIMLoco 的完整类别和比例，仅将尺寸按 Solo12 缩放为
  `geometry_scale=0.94`。
- 完整地形比例为 `[0.1, 0.2, 0.3, 0.3, 0.1]`。
- 最终命令范围为：
  - 前向速度 `[-1.0, 1.0] m/s`
  - 横向速度 `[-1.0, 1.0] m/s`
  - yaw 角速度 `[-3.14, 3.14] rad/s`
  - heading `[-3.14, 3.14] rad`

## 3. 前置基础能力

在障碍课程前，先完成基础步态、`0.32 m` 站高、姿态修正、完整场景和动力学
适配，得到进入障碍课程的 `model_4320.pt`。后续 A/B/C 和最终训练均从这一
有效 checkpoint 链连续恢复，不从零重新训练。

## 4. 阶段 A：低难度障碍

从 `model_4320.pt` 追加 600 次迭代，得到 `model_4920.pt`。

- 任务：`solo12_v3_1_obstacle_a`
- 初始地形等级：0–2
- 前向速度：`[0.2, 0.5] m/s`
- 横向速度：`[-0.15, 0.15] m/s`
- yaw 角速度：`[-0.3, 0.3] rad/s`
- heading：`[-0.5, 0.5] rad`
- 最低摆腿峰值目标：`0.07 m`

本阶段取消会压制越障抬腿的摆腿高度上限惩罚，保留最低离地高度约束，让模型
形成遇到障碍主动抬腿的能力。

## 5. 阶段 B：中等难度障碍

从 `model_4920.pt` 追加 500 次迭代，得到 `model_5420.pt`。

- 任务：`solo12_v3_1_obstacle_b`
- 初始地形等级：0–5
- 前向速度：`[0.15, 0.7] m/s`
- 横向速度：`[-0.25, 0.25] m/s`
- yaw 角速度：`[-0.6, 0.6] rad/s`
- heading：`[-1.0, 1.0] rad`
- 最低摆腿峰值目标：`0.09 m`

本阶段将阶段 A 的越障动作扩展到中等不平整地面和楼梯。

## 6. 阶段 C：完整地形高度

采用最终有效的 command-progress 版本：

1. 从 `model_5420.pt` 追加 100 次迭代，得到 `model_5520.pt`。
2. 从 `model_5520.pt` 再追加 200 次迭代，得到 `model_5720.pt`。

配置范围：

- 任务：`solo12_v3_1_obstacle_c`
- reset 时初始地形等级：0–7
- 等级 8–9 通过正常地形课程逐步进入
- 地形晋级同时参考命令完成度
- 前向速度：`[0.1, 0.7] m/s`
- 横向速度：`[-0.4, 0.4] m/s`
- yaw 角速度：`[-1.5, 1.5] rad/s`
- heading：`[-3.14, 3.14] rad`
- 最低摆腿峰值目标：`0.11 m`

不在恢复训练时直接把全部环境放到等级 0–9，避免地形等级和策略能力同时
塌缩；最高两级仍属于阶段 C 的训练范围。

## 7. 完整动力学与楼梯强化

从阶段 C 的 `model_5720.pt` 依次执行：

1. 完整动力学适应 200 次迭代，得到 `model_5920.pt`。完整命令中保留 30% 的
   纯前向采样，提高前向越障样本密度。
2. 楼梯专项 100 次迭代，得到 `model_6020.pt`。专项覆盖反复上下楼梯，台阶
   高度为 `0.081–0.199 m`，前向速度为 `0.2–0.7 m/s`。
3. 恢复完整动力学训练 100 次迭代，得到 `model_6120.pt`，消除楼梯专项造成的
   场景偏置。

## 8. 最终全范围训练

从 `model_6120.pt` 使用完整地形、完整命令和完整随机化连续训练两段，每段
500 次迭代。训练运行到 `model_7120.pt`，根据验收结果选择 `model_7100.pt`
作为动作延迟训练的父 checkpoint。

最终随机化范围为：

- base 附加质量：`[-0.635, 1.906] kg`
- COM XYZ 偏移：每轴 `[-0.02, 0.02] m`
- link 质量倍率：`[0.7, 1.3]`
- 摩擦：`[0.7, 1.25]`
- 恢复系数：`[0.0, 0.2]`
- 电机强度倍率：`[0.9, 1.1]`
- Kp、Kd 倍率：分别为 `[0.9, 1.1]`
- 初始关节角倍率：`[0.8, 1.2]`
- 关节摩擦：`[0.0, 0.02]`
- 关节阻尼：`[0.0, 0.01]`
- 外力 XYZ：每轴 `[-30, 30] N`
- push：每 16 秒一次，XY 最大速度变化 `1.0 m/s`
- 电机、Kp、Kd 和初始关节角均按关节独立采样
- 观测延迟：关闭

## 9. 动作延迟训练

从 `model_7100.pt` 保持完整地形、命令和随机化范围，追加 500 次动作延迟训练。
动作延迟不是观测延迟：策略每 20 ms 输出一次动作，执行端在本周期内随机延后
0、1、2 或 3 个 5 ms 仿真步，因此对应 `0/5/10/15 ms`。

训练运行到 `model_7600.pt`。对末段 9 个 checkpoint 在 19.9 cm 楼梯上筛选后，
选择兼顾速度通过率和跌倒/重置次数的 `model_7540.pt`。

## 11. 7540 阶段验收结果

验收使用 50 个并行环境、15 秒 rollout、`0.5 m/s` 前向命令和完整验收随机化。
单个环境 15 秒平均前向速度不低于 `0.35 m/s` 时记为速度通过。

`model_7540.pt` 连续两轮结果：

- 高难不平整地面：`98% / 98%`
- 14.9 cm 楼梯：`100% / 100%`
- 19.9 cm 楼梯：`82% / 90%`

该模型通过当前仿真可行性门槛。19.9 cm 楼梯仍存在较多跌倒/重置，因此结果
不应解释为该高度已经稳定准出；实机测试需要将其作为重点风险场景。

## 12. 8040 后的 armature 动力学适应

部署侧确认了非零 armature 后，以已验收的 `model_8040.pt` 为能力基线，只适应
armature；关节 friction loss 和 damping 保持原训练范围，不改成部署 MJCF 的固定值。

基线模型：

- run：`Sep21_13-25-22_mixed_stability_replay_8020_to8080`
- checkpoint：`model_8040.pt`

第一段从 8040 使用 1024 个环境训练 500 iteration：

- run：`Sep23_06-03-52_armature_only_adapt_8040_to8540`
- friction loss：所有关节 `[0.0, 0.02]`
- damping：所有关节 `[0.0, 0.01]`
- hip/thigh armature：`[0.0, 0.00504]`
- calf armature：`[0.0, 0.02016]`
- 中间父 checkpoint：`model_8320.pt`
- SHA-256：`7b5f7ac917bae5c925727756d47a0ec0732e4e74b18e42e8235ddbddb9d69812`

连续均匀 armature 能改善部署端点，但精确 `armature=0` 在连续分布中的概率为零，
旧动力学楼梯和不平整地面出现遗忘。因此没有继续使用该段后期 checkpoint，而是从
8320 增加零端点 replay。

第二段从 8320 使用 1024 个环境训练 200 iteration：

- run：`Sep23_06-52-17_armature_zero25_replay_8320_to8520`
- 25% 环境的全部关节固定 `armature=0`
- 75% 环境继续在上述完整 armature 范围内采样
- friction loss 和 damping 范围保持不变
- 最终选定 checkpoint：`model_8520.pt`
- SHA-256：`200a9be90b921b1dd783e8aaedb836ddc4d1db6ae0fd2ed6de2446a1539f74e7`

1024 环境实例化检查得到 278 个完整零 armature 环境，占 27.15%；其余样本实际覆盖
到 hip/thigh `0.005039/0.005035`、calf `0.020153`。实际 friction loss 覆盖
`[0,0.02]`，damping 覆盖 `[0,0.01]`。

## 13. 8520 动力学适应验收

最终命令矩阵每个 case 使用 10 个环境、10 秒 rollout、seed 1。覆盖平地
`0.3/1.0 m/s` 和组合命令，高难度不平整地面 `0.3/0.5/1.0 m/s` 和组合命令，
以及 14.9 cm 楼梯 `0.3/0.7 m/s`。

旧动力学回归：

- 8040：9 个 case 平均通过率 0.900，平均速度比 0.806，共 11 次跌倒
- 8520：9 个 case 平均通过率 0.878，平均速度比 0.888，共 10 次跌倒
- 两者平地和 14.9 cm 楼梯均全部通过；8520 的总体稳定性与 8040 同一水平

armature 适应：

- 8040 在部署标称 armature 下：平均通过率 0.467，速度比 0.630，共 263 次跌倒
- 8520 在部署标称 armature 下：平均通过率 0.867，速度比 0.877，共 9 次跌倒
- 8520 在 25% 零端点加完整随机范围下：平均通过率 0.889，速度比 0.872，共 7 次跌倒
- 8520 在标称和随机 armature 下的平地与 14.9 cm 楼梯均全部通过

另对高难度不平整地面和 14.9 cm 楼梯做了三个 seed 的独立复测。最终选择 8520，
不选择训练末端只是因为 checkpoint 更新更晚，也不采用已放弃的 damping/friction
扩大分支。
